# **App Name**: WhatsCrop

## Core Features:

- Smart-Fit Drag & Drop: Seamless image upload supporting high-resolution JPG and PNG formats with instant workspace loading.
- Live Circle Preview Mask: An overlay system that accurately simulates how the profile picture will appear within WhatsApp's circular frame in real-time.
- AI HD Enhancement Tool: A generative tool used to intelligently restore clarity and detail when scaling lower-resolution images to the 1080x1080 export size.
- Ambient Blur Generator: Automatically generates a aesthetically pleasing blurred extension of your photo to fill the canvas without cropping the subject.
- Color Canvas Studio: Allows for precise background color selection using a palette of modern presets or a custom hexadecimal picker.
- Direct Spatial Manipulation: Smooth pinch-to-zoom and drag interactions for positioning the image precisely within the square frame.
- High-Fidelity Render & Export: Process and download your final design as a high-density 1080x1080 square image, ready for instant profile updates.

## Style Guidelines:

- A sophisticated dark mode palette featuring #25D366 (WhatsApp Green) as the primary brand color to provide visual continuity with the user's destination platform.
- Background: #111613 (a deep, desaturated green-black). Accent: #75E862 (a lighter, vibrant lime green used for CTA clarity).
- A pairing of 'Space Grotesk' for technical, modern headlines and 'Inter' for highly readable functional UI text.
- Clean, thin-stroke SVG line icons with rounded ends to maintain a premium, friendly aesthetic.
- Single-page, centered focus layout prioritizing the visual canvas, optimized for vertical scrolling on mobile and expansive workspace on desktop.
- Liquid transitions between cropping modes and a subtle pulse effect on the drag-and-drop zone during active hover states.
